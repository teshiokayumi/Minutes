# 完成版（講師用・救済用）

ハンズオンでうまく進めなかったときに使うファイルです。最初から開く必要はありません。

| ファイル | いつ使う？ | 使い方 |
| --- | --- | --- |
| `CLAUDE_完成版.md` | ステップAでつまずいたとき | 中身を、フォルダ直下の `CLAUDE.md` にコピーする |
| `gitignore_完成版.txt` | ステップAでつまずいたとき | 中身を、フォルダ直下の `.gitignore` にコピーする |
| `matome_完成版.md` | ステップB・Dでつまずいたとき | 中身を `.claude/commands/matome.md` にコピーする |
| `出力例_2026-09-13-研修ふりかえり.md` | ステップCの答え合わせ | 自分のまとめと見比べる |

※ 出力例は、ステップCで「個別相談は次回の休憩時間に相談枠を作る」「会場の空き確認は未決のまま」と答えて保存した場合の一例です。言い回しや並び順が違っていても、数字・決まったこと・未決が合っていれば大丈夫です。
