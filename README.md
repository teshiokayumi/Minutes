# Minutes：アンケートと議事録を「使えるまとめ」に変える

AIセミナー シリーズ第2回「紙からはじめるAIエージェント」（2026年11月28日・熊本 XOSS POINT.）のハンズオン教材です。

**当日の手順ページ：https://teshiokayumi.github.io/Minutes/** （コピーボタンつき。当日はこのページを見ながら進めます）

研修のアンケートと議事録を Claude Code に読ませて、次の仕事でそのまま使える**まとめ（コンテキスト資料）**を作るコマンド `/context` を作ります。

## 事前に必要なもの

- **Claude Pro 以上の契約**（無料プランでは Claude Code を使えません）
- **Claude Code**：ターミナル版か、Claude デスクトップアプリ版のどちらか1つ
- **ログインと動作確認**：「こんにちは」と送って返事が返ってくるところまで
- **最新版への更新**：当日は Opus 5.5 を使います

## ダウンロードのしかた

1. このページの緑の「**Code**」ボタン →「**Download ZIP**」をクリック
2. ダウンロードした `Minutes-main.zip` を展開する（デスクトップなど、わかる場所に）
3. 展開してできた `Minutes-main` フォルダで Claude Code を起動する

**ターミナル版**

```
cd Minutes-main
claude
```

**デスクトップアプリ版**：「Code」タブを開き、「Select folder」で `Minutes-main` フォルダを選びます。

## 入っているもの

| ファイル | 中身 | 使うところ |
| --- | --- | --- |
| `input/anket-2026-09-13.csv` | 練習用のアンケート（架空のデータ） | 全体 |
| `input/gijiroku-2026-09-20.txt` | 練習用の議事録メモ（架空のデータ） | 全体 |
| `context/_テンプレート.md` | まとめの型 | ステップC |
| `CLAUDE_追記ルール.md` | CLAUDE.md に書くルール | ステップA |
| `gitignore_追記.txt` | `.gitignore` に書く行 | ステップA |
| `context.md` | 手順書（`/context` コマンドの中身） | ステップB |
| `完成版/` | うまくいかなかったときの完成形と、出力例 | 困ったとき |
| `index.html`、`images/` | 当日の手順ページ（GitHub Pages で表示） | 全体 |

練習用データはすべて架空です。アンケートには、わざと個人名と電話番号を1件だけ入れてあります（エージェントが消せるかを確かめるため）。

## 当日の流れ（後半）

| ステップ | やること |
| --- | --- |
| A | 任せる範囲を決める（`CLAUDE.md` と `.gitignore` を作る） |
| B | 紙の要件を手順書にする（`.claude/commands/context.md` を作る） |
| C | `/context` を動かして、確認して、保存する |
| D | できたまとめを使い回す／チェック項目を育てる |

くわしい手順は、手順ページ（https://teshiokayumi.github.io/Minutes/）を見てください。

## 大切な約束

- 作った道具とまとめは自分のパソコンに残ります。**Web には公開しません**（Vercel などにデプロイしません）。
- ただし、**AI が資料を読むときは、中身が AI のサービス（Anthropic 社）へ送られて処理されます**。社外秘のものは入れないでください。本物の資料を使うときは、会社のルールで AI に入れてよいかも確認してください。
- 本物のアンケートや議事録を入れる `input/` と、まとめを保存する `context/` は、`.gitignore` で GitHub に上がらないようにします。共有するのは「手順書」と「テンプレート」だけです。
